# ADP binding in AmAc at 20 °C

## Run

From the repository root after installation:

```bash
protein-ligand-fit examples/adp_amac_20c/fit.yaml
```

The command fits the three CSVs independently with the sequential-adduct model. It writes results to `output/sequential_adduct/` within this folder. Inspect `AMAC_20C_fit_summary.svg` for the combined figure and `AMAC_20C_stat_summary.csv` for the replicate constant summary. Each replicate also has `AMAC_20C_N_kd.csv` and `AMAC_20C_N_sequential_adduct_fit.svg`; the optimizer log is `sequential_adduct_log.txt`.

![Combined bound-state fit with observed replicate error bars](fit_preview.png)

The preview is converted from the combined fit SVG generated by the command. Points are means of observed fractions at each measured concentration; bars are sample SD where at least two replicates measured that concentration. Lines are the mean of the three independently fitted model curves. Missing replicate measurements are not interpolated.

## Input and settings

| Item | Value |
|---|---|
| Protein | SR, 1 µM total |
| Ligand and buffer | ADP in AmAc, 20 °C |
| Data | Three replicate bound-state fraction tables; `Entry` is total ADP in M |
| Model | Sequential adduct, 7 specific steps and 2 additional adduct slots |
| Fit | Each replicate separately; nonspecific affinity constrained weaker than specific affinity |

Change `colormap: Greens` in `fit.yaml` to another Matplotlib map to recolor all fit curves. To color pure-specific and nonspecific-containing components separately, enable deconvolution and set `specific_colormap` and `nonspecific_colormap` as shown in the YAML comments.

The replicate concentration grids differ:

| Total ADP (µM) | Replicates measured |
|---:|---:|
| 0, 5, 10, 50 | 3 |
| 20, 100 | 2 |
| 30 | 1; no error bar |

The fitted constants are model-dependent descriptive outputs; inspect residuals before using them as physical binding-site estimates.
